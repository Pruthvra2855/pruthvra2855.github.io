## 🌟 What is DocFlow?

DocFlow is a free, offline desktop application that turns your PDF files into clean, editable Markdown documents. Whether you have Persian, Arabic, or English PDFs, DocFlow handles them all with built-in OCR (text recognition) technology. You can even edit your converted documents right inside the app with its visual editor.

## ✨ Key Features

### 📝 PDF to Markdown Conversion
DocFlow reads your PDF files and converts them into Markdown format. Markdown is a simple text format that works everywhere—from GitHub to note-taking apps. Your converted files are easy to edit, share, and repurpose.

### 🌍 Persian and Arabic Support (RTL)
Unlike many PDF tools, DocFlow fully supports right-to-left languages. Persian and Arabic text is converted accurately, preserving the correct reading order and formatting. This makes DocFlow one of the few tools that handle RTL PDFs properly.

### 🔍 Built-in OCR (Text Recognition)
Have a scanned PDF or an image-based document? DocFlow's OCR technology extracts text from images and scans. You don't need to type anything manually—just let DocFlow do the work. It recognizes text in multiple languages, including Persian and Arabic.

### 🖊️ WYSIWYG Markdown Editor
After conversion, you can edit your document in a "What You See Is What You Get" editor. This means you see the final formatted result as you type, just like in Word or Google Docs. No need to learn complex Markdown syntax—the editor handles it for you.

### 🖥️ Simple Desktop App
DocFlow is a desktop application, meaning it runs directly on your computer. It's fast, reliable, and doesn't require a browser. The interface is clean and straightforward, designed for everyday users.

## 🆘 Troubleshooting

### DocFlow won't start
- Make sure you've downloaded the complete file
- Try running the application as administrator (right-click, then "Run as administrator")
- Check if your antivirus is blocking the app—if so, allow it through

### Conversion is slow
- Close other programs that might be using memory
- For scanned PDFs, OCR takes time. Be patient with large documents

### Persian text appears reversed
- Check that your document is properly saved in UTF-8 encoding
- Try converting again with the "RTL Mode" option enabled (if available)
